     * **Bottom Pivot Alignment**: `pts[:, 1] -= y_min`, ensuring `min_y == 0.0` (Three.js Y-up convention) or `min_z == 0.0` (Blender Z-up convention). Prevents floating or subterranean sinking.
     * **Horizontal Centering**: `pts[:, 0] -= (x_min + x_max) / 2.0`, `pts[:, 2] -= (z_min + z_max) / 2.0`, centering the asset around (0, 0).
     * **Metric Scaling**: `scale = target_height / (y_max - y_min)` uniformly scales all axes.

       - *Convex Hull*: Watertight convex polyhedron via `scipy.spatial.ConvexHull` with vertex subsampling if N > 48, computing vertices, triangular simplices, volume, and surface area. Box hull fallback if Qhull fails.
     * **Pure-Python glTF 2.0 Binary Codec**:
